# Hayool OS — Go-To-Market, Brand & Monetization Specification
Version: 7.2 overlay (V6 detail adopted)
Status: Adopted normative detail; subject to V7.2 resolutions and release mapping

## 1. Category

Long-term platform category:

**AI-native Extensible Business Operating Platform**

Initial sales category:

**AI-native Operating System for project-based companies**

Do not lead early-market sales with “software for every business in the world.”

Universal breadth is an architectural/partner story until verified industry packs exist.

## 2. Core promise

General:
**Run it. Customize it. Extend it.**

Intent/product narrative:
**Tell Hayool what needs to happen — use what already exists, customize it, or build the missing capability on the same platform.**

Initial project-company sales narrative:
**From business goal to the right team, execution and economics — in one system.**

Persian direction:
**بگو چه می‌خواهی؛ استفاده کن، شخصی‌سازی کن، یا همان‌جا قابلیت جدید بساز.**

## 3. Positioning pillars
1. Understand the work.
2. Build the right workforce.
3. Execute in one system.
4. Know the economics.
5. Improve from outcomes.

## 4. Initial ICP
Primary:
- software houses
- digital agencies
- design/branding firms
- marketing/SEO firms
- consultancies

- distributed professional teams.

Initial size focus:
roughly 5–200 workers, subject to discovery validation.

Typical pain:
- mixed employees/freelancers
- recurring client projects
- margin visibility problem
- fragmented tools
- capacity/staffing pain.

Needs fair scope, pay, growth and trust.

## 19. GTM anti-patterns
Do not:
- target every industry initially

- underprice implementation/support

## 21. Competitive frame

Competitors validate adjacent categories, but Hayool should not position as a direct feature-for-feature clone.

| Category / examples | Strong at | Hayool differentiation target |
|---|---|---|
| Enterprise HCM / Workday | HCM, workforce planning, skills, finance/AI agents | project-company economics + managed network + local-first + work graph |
| Workflow / ServiceNow | enterprise workflows, service operations, autonomous agents | workforce design + talent network + project margin/delivery |
| Talent intelligence / Gloat, Eightfold | skills, internal mobility, project staffing | end-to-end commercial execution + external network + finance |
| Talent marketplace / Upwork | external supply, marketplace liquidity | internal + external + managed delivery + company operating system |
| EOR/contractor / Deel | global employment/payroll/contractor operations | work design, project execution, pricing and outcome learning |
| ERP/project tools | operations/projects/finance | human+AI workforce composition and learning loop |

Vendors change quickly. Revalidate before sales materials.

## 22. Competitive message

Do not say:
“we replace Workday/Upwork/Deel.”

Say:
“Hayool closes the loop between work design, workforce, delivery and economics for project-based companies.”

## 23. Sales objections

### “We already use project/accounting tools.”
Response direction:
Hayool’s value is not another task list; it connects capacity, talent, client economics and AI automation.

### “We already use ChatGPT/Claude.”
Response direction:
Hayool governs context, permissions, workflows, decisions, budgets and business data around models.

### “We already use freelancers.”
Response direction:
Hayool turns ad-hoc freelancer sourcing into a managed, evidence-backed, economically measurable system.

### “AI hiring sounds risky.”
Response direction:
Autonomy is configurable; high-impact actions default to explainable human review and jurisdiction policy.

## 24. Brand proof hierarchy

Marketing claims should be earned in this order:

1. “Run projects and economics in one place.”
2. “Plan capacity and source talent intelligently.”
3. “Design the human + AI workforce.”
4. “Optimize from outcome data.”

Do not lead with the most futuristic claim before the underlying workflows are proven.

## 29. Developer psychological value

Developers must feel:
- API contracts are stable;
- their app remains theirs;
- they can monetize;
- permission changes are explicit;
- the platform will not break them casually.

A healthy ecosystem is a brand asset.
