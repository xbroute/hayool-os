## Canonical value types

Detailed independent contracts: `../finance/BUDGET_COST_CENTER_CONTRACT.md`, `../finance/FIXED_ASSET_ACCOUNTING_CONTRACT.md`, `../operations/INCIDENT_MANAGEMENT_CONTRACT.md`, `../operations/ASSET_MANAGEMENT_CONTRACT.md`, `../operations/OPERATIONAL_HEALTH_TELEMETRY_CONTRACT.md`, `../security/SECRETS_VAULT_CONTRACT.md`, `../security/DATA_CLASSIFICATION_KEY_EGRESS_CONTRACT.md`, `../data/PORTABILITY_IMPORT_REVERSAL_CONTRACT.md`, `../domains/COMMERCE_ORDER_DISPUTE_CONTRACT.md`, `../domains/INVENTORY_STOCKTAKE_VALUATION_CONTRACT.md`, `../domains/MANAGED_NETWORK_VETTING_REPLACEMENT_CONTRACT.md`, `../platform/STUDIO_BUILDERS_EXECUTION_CONTRACT.md`, and `../ai/MEETING_INTELLIGENCE_CONTRACT.md`. Their tests and failure cases compose with this table, never replace tenant/finance/privacy hard gates. Risk, issue, operational incident, support ticket and security incident have distinct aggregate IDs and state machines even when one event links several.

Money: decimal string amount, currency identifier, currency exponent metadata, functional currency, rule snapshot. API never accepts binary floating point as authoritative amount. Toman presentation uses explicit unit and deterministic 10 IRR conversion; storage/contract explicitly labels IRR. Quantity: decimal string plus UOM; dimensional conversions only. Instant: UTC timestamp; local date is separate civil date with calendar/timezone, never converted to midnight UTC without semantics. Effective intervals are half-open [from,to); rule history is append-only with recorded-at as well as effective-at.

## Common capability contract

Input schema/version, owning module, authorization action, tenant/entity scope, field-level scopes, policy context facts, validation, concurrency, idempotency retention, audit event, public event, sensitive data class, error codes, retry/compensation, observability, acceptance scenario and retention must be specified before a task enters implementation. Schema changes are additive first. A task missing these fields is NOT_READY rather than agent-invented behavior.

Error classes: VALIDATION, NOT_FOUND_OR_NOT_VISIBLE, CONFLICT, POLICY_DENIED, POLICY_PENDING, PROVIDER_UNAVAILABLE, OUTCOME_UNKNOWN, QUOTA_EXCEEDED, UNSUPPORTED_VERSION. Include safe message/action/correlation, not secrets/internal stack traces. Policy pending UI identifies missing user-suppliable facts without exposing restricted screening internals.
