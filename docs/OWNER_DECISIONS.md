2026-09-25. `OD-001–030` in the adopted V6 owner sheet are proposed working defaults, not signatures. This document does not change them. ## Exactly what is needed before product coding

The first phase is documentation-only. To begin a later implementation phase, the owner must explicitly lift that instruction and supply or authorize the target project repository/workspace destination and access. We have not discovered a Hayool Git repository. There is no need to choose a live bank, AI provider, launch country, price, fundraising amount, marketplace take rate or employing entity to build M0.0 and the policy-disabled V1.0 foundation. Engineering can use synthetic fixtures and zero paid external-API budget until authorized. No automatic migration from this package into a protected repository is claimed. If a project repository already exists, its contents and governing decisions must be inspected before any code write; do not create a competing authoritative repository.
