# Hayool OS — V7 Rebaseline Changelog

## Why V7

V6 correctly shifted from “Hayool builds every industry” to:
**Excellent Core + Studio + Developer Platform + Ecosystem.**

V7 completes the execution model.

## Major changes

### 1. Architecture completeness vs evidence readiness
Introduced separate Design / Implementation / Verification / Jurisdiction / Market completeness.

### 2. Jurisdiction Context
Replaced simplistic country-only reasoning with multi-jurisdiction resolution.

### 3. Workforce sourcing policy
Added Domestic / Allowlist / Regional / Global-if-eligible / Approval modes and hard eligibility before ranking.

### 4. Iran working sourcing default
Owner-requested domestic-only sourcing becomes an explicit product policy, not an unsupported legal claim.

### 5. Provider Availability Matrix
Cloud/AI/payment/bank/SMS/etc availability becomes executable policy input.

### 6. Outcome-gated release train
Every milestone proves an end-to-end outcome.

### 7. Stronger autonomous SDLC
Added explicit debugging/update loops and evidence-bound autonomy promotion.

### 8. Legal-update lifecycle
AI may detect changes, but high-impact legal policy requires source verification and qualified review.

### 9. Product Claims Register
Marketing claims become evidence-bound and maturity-aware.

### 10. Ecosystem Trust Compact
Added first-party vs partner conflict policy, permission re-consent and abandonment rules.

### 11. Global bank/payment architecture
Local rails/providers are adapters; finance core remains provider-neutral.

### 12. Financial operating model gate
Commercial GA requires actual COGS/support/working-capital scenarios.

### 13. Accessibility gate
WCAG target plus jurisdiction-specific mapping and manual assistive-technology evidence.

### 14. Mandatory project state
`PROJECT_STATE.md` and `NEXT_ACTIONS.md` become required execution-control artifacts.

## No capability removed

V7 does not remove:
- universal kernel
- Studio

- marketplace
- workforce
- commerce

- logistics
- manufacturing
- agriculture
- website/eCommerce
- AI

It changes the implementation and evidence order so breadth does not destroy quality.
