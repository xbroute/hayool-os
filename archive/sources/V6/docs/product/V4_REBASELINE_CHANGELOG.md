# Hayool OS V4 Rebaseline Changelog

V4 is a strategic rebaseline, not a feature reset.

## Major changes from V3

1. Category sharpened to **AI-native Work & Workforce Operating System**.
2. Initial GTM narrowed to project-based digital/professional-service companies.
3. Work/Capability made the fundamental domain primitive before Job Title.
4. Added formal Work Graph & Capability Ontology.
5. Added fair-exposure/cold-start strategy to Talent Matching.
6. Added Trust, Safety & Marketplace Integrity as V1 core.
7. Added explicit protection against opaque universal worker scoring.
8. Added purpose limitation for workforce evidence.
9. Added separate SaaS / AI / Managed Workforce unit economics.
10. Added detailed GTM, brand and monetization spec.
11. Added release/market-readiness gates.
12. Added strategic risk register.
13. Strengthened Engineering Autopilot:
    - protected tests
    - runner isolation
    - build provenance
    - expand/contract migrations
    - reviewer diversity
    - test-oracle risk.
14. Strengthened Learning Intelligence:
    - champion/challenger
    - drift
    - feature registry
    - exploration safety
    - causal humility.
15. Added Billing/Recurring Services, Procurement/Vendors, shared Conversation/Form/Notification engines, OKR/KPI, AI Evaluation Lab, Product Analytics and white-label details back into canonical Master.
16. Added Software Delivery integration, AI Project Architect/PM, Personal Work Copilot and Automation Builder.
17. Added multi-currency/FX, retention/legal hold and translation governance.
18. Added future optionality hooks:
    - Work API/MCP
    - B2B Capacity Exchange
    - Verified Outcome Credentials
    - Workforce Academy
    - Vertical Packs
    - Benchmark Intelligence
    - Managed Outcome Marketplace
    - Digital Worker marketplace.
19. Updated M0 prompt and review gate to use all V4 strategic inputs.
20. Rewrote beginner Runbook so manual ChatGPT Work review is optional, not an Autopilot bottleneck.

## Unchanged fundamentals

- Modular monolith first.
- PostgreSQL authoritative core.
- Cloud + Dedicated + On-Prem.
- Annual license + AI Credits.
- deterministic accounting/payroll/permission authority.
- TypeSafe/Jev behind provider abstraction.
- Human-in-the-loop/guarded autonomy for high-impact actions.
- Persian/RTL + English/LTR.
- Iran country pack first.
